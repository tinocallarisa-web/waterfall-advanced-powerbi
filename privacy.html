Privacy Policy

Product: Waterfall Advanced  |  Publisher: TCViz  |  Last updated: 2026-09-12

1. Data Collection

Waterfall Advanced does not collect, transmit, store, or process any personal data outside your Power BI environment. All data processing occurs locally within your Power BI report session.

2. Data Processed Locally

The visual processes only the data you explicitly add to its data roles (Category, Value, Target, Bar type, Order, Tooltips, Colour). This data is used exclusively to render the waterfall chart within your report and is never sent to any external server by TCViz.

3. No External Connections

The visual makes no network calls of any kind: no telemetry, no analytics, no content delivery network, no external endpoints. It reads no local files, and it persists nothing outside the report beyond the formatting choices you make in the format pane, which are saved inside the report file itself.

Versions up to 1.0.8.0 offered an optional AI narrative feature that sent aggregated chart data to an AI provider using an API key you supplied. That feature was removed in version 1.1.0.0, together with the Finance tier. No build from 1.1.0.0 onwards contains any code that contacts an external service.

4. License Verification

License status is verified through Microsoft's official IVisualLicenseManager API, which communicates with Microsoft AppSource infrastructure. TCViz does not receive or store any personal information through this process.

5. Cookies & Tracking

This visual does not use cookies, local storage, or any tracking technologies.

6. Third-Party Services

Other than Microsoft's own licence verification described in Section 4, this visual does not integrate with any third-party service: no analytics, no advertising, no data sharing.

7. Children's Privacy

This visual is a business intelligence tool not directed at children. We do not knowingly collect data from individuals under 13 years of age.

8. Contact

For privacy questions, contact: support@tcviz.com
