Waterfall Advanced 1.1.1.0. Full notes: CERTIFICATION-NOTES.md in the repo.

RESUBMISSION (1200.1.1.3)
Last submission uploaded the 1.0.8.0 package by mistake. Repo and package are now 1.1.1.0;
code identical to 1.1.0.0, renumbered because that number was already recorded.

EXTERNAL CALLS REMOVED
Earlier versions had AI narratives calling api.anthropic.com and api.openai.com, which a
certified visual may not do (the CSP blocked them). Code, format card and capabilities
object are gone. privileges stays []. No fetch, XHR or WebSocket in src/.

LICENSING REWRITTEN
The old code called getAvailabilityStatusForServicePlan(), not in IVisualLicenseManager:
it threw, the catch swallowed it and a hostname fallback left every published user on Free.
Now getAvailableServicePlans(), matching spIdentifier to the Pro plan (the offer also has a
free plan, so "any active plan" would be wrong). Active and Warning accepted.
isLicenseUnsupportedEnv and isLicenseInfoAvailable honoured. Repaints when it resolves.

NO LICENSING UI OF OUR OWN
Padlock overlay, upgrade banner and landing badge removed. notifyFeatureBlocked and
notifyLicenseRequired carry the purchase path, fired from metadata.objects (only what the
user set), so nothing fires on an untouched report.

DATA
Categorical dataView only (Category, Value, Target, Bar type, Order, Tooltips, Colour). No
local file access; nothing persisted beyond formatting properties in the .pbix.

TIERS
Free: the whole bridge - totals, subtotals, deltas, connectors, both orientations,
drilldown, target line, conditional formatting, colour-blind palette, hatched decreases,
summary cards, cross-filtering, bookmarks, keyboard, high contrast. Twelve drivers; above
that the smallest group into "Others" and the bridge still closes on the same figure. No
watermark.
Pro: all drivers, data table, IBCS mode, label density controls.

TEST
Category = P&L line, Value = amount, Bar type = total/subtotal/delta aggregated as FIRST,
Order = sequence. Without a licence turn on IBCS mode or the data table: the free result
stays and Power BI raises its notification; turn it off and it clears.
